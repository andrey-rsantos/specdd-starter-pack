# Plans — índice

Planos, investigações e rascunhos que ainda não viraram task.
**Não é fonte de verdade e não autoriza execução:** trabalho só acontece via `docs/NOW.md`.
Regras de uso: `docs/RULES.md` (§ Planos e rascunhos).

## Ciclo de vida
1. Rascunhe aqui (`NNN-slug.md`), livre e sem compromisso.
2. Discuta/ajuste com o usuário.
3. Aprovado → quebre em itens do **Backlog** de `docs/NOW.md`, referenciando o arquivo.
4. Se virar regra/contrato → `docs/SPEC.md`. Se virar decisão arquitetural → `docs/ARCH.md`.
5. Marque o status no topo do plano ao fechar ou descartar.

## Modelo de plano
```markdown
# NNN — <título>
Status: rascunho | aprovado | concluído | descartado
Data: <AAAA-MM-DD>

## Problema / oportunidade
## Proposta (em passos pequenos)
## Alternativas consideradas e por que não
## Riscos e o que pode dar errado
## Impacto em SPEC / ARCH
## Itens que iriam para o Backlog
```
